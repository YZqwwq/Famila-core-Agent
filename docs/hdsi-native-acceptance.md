## 测试与结果

- `npm run build` 通过；`npm test` 133/133；`node --test tests/*.test.cjs` 10/10；边界检查 252 个 TS 文件通过。现有故障恢复与突发并发的 HDSI 深度用例主要运行 fast，不等于 native 的全部故障情形已覆盖。
- `node scripts/hdsi-behavior-compare.cjs --compat-only`：本地固定决策，3 条用户消息、3 条可见消息、3 次完整叙事，3 条 Alter 历史、累计值 6。报告 `evals/companion_zh/reports/hdsi-behavior-fixture-1794682172803/results.json`。
- `node scripts/hdsi-behavior-compare.cjs --live --native-acceptance`：通过 Fastify `POST /messages`、持久化收发队列调用包内原生 HDSI；原生消息合并、打字、气泡配置均保留。独立数据目录，qwen3.8-max，最多 14 请求、每请求 2048 输出 token；实际 8 请求。报告 `evals/companion_zh/reports/hdsi-behavior-live-1794682203828/results.json`。

每条真实消息收到完整事件、非空回复；7 条消息分别重复投递，均返回相同文本且未新增模型调用。5 轮训练生成 5 次完整叙事，重启后共 7 次；没有 fast 尾任务归档。前 5 次模型输出未产生 Alter 历史，重启两轮产生 2 条；不能要求每次模型输出都有情绪变化。固定决策测试另行证明明确提供的情绪增量没有丢失。

| 重启后询问约定 | 问我现场怎么样 | 16.62 秒 |

平均 16.92 秒，范围 15.62–18.53 秒。这是 HTTP 注入收到完整响应的耗时，不是首 token 指标，也不是并发压力或 P95。

“睡吧”受测试实际凌晨时段和原生生活叙事影响，有时间背景，但没有充分承接用户情绪；“嗯”等回复较机械。约定回答“问我现场怎么样”存在指代歧义。因此只判目标内容基本识别，不能判自然接话质量通过。

5 轮后已自动形成 2 条持久事实；显式调用原生整理返回 false、没有新增事实。重启收窄最近上下文后，回忆目标字段正确，但原生检索仍注入持久剧集、叙事和原始证据（见 request-7.json），因此只能证明重启后的原生检索回忆可用，不能证明仅凭结构化事实或跨天长期记忆通过。

## 验收边界

原生内核经 Famila 队列进行基本文本聊天、重复请求重放、逐轮叙事保留和正常重启回忆通过本轮检查。自然度、低延迟、native 专属强杀恢复/突发并发、多用户隔离、跨天关系、主动联系尚未完成验收。继续保持 native，下一步先补 native 故障与连续到达测试，再处理叙事对接话和等待时间的影响。
