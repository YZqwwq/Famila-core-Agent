# 外围情景行动 Harness

## 边界与流程

不修改 `vendor/hdsi`。新增代码仅位于 Famila runtime 和测试脚本。HDSI 仍组装上下文、接收完整最终剧本并执行原生状态提交。父进程启动仅监听回环地址、使用随机 token 的模型代理，子进程只知道代理凭据。

代理只对 user-message 主叙事启用行动协议；记忆整理等请求直接透传。普通聊天可以一次返回最终剧本，不增加独立路由模型。需要行动时，外围允许多次模型与工具往返，HDSI 对此仍只收到一个最终模型响应。原生请求中的 provider `response_format=json_object` 在行动往返时由代理移除，避免阻止情景文本；最终结果仍必须符合原有 JSON 剧本格式。这不是要求模型输出结构化工具 JSON。

```text
她决定先记下来。
【工具调用：保存笔记】
标题：周末出行
内容：周六出门带雨伞
【工具结束】
```

仅解析当次新生成的独立文本动作，要求一个完整块且以工具结束标记收尾。不扫描历史、JSON 剧本或工具观察。程序转换为工具名称和参数；未知工具、缺参、额外参数不执行。正文在最后的“内容：”下，可多行；正文内看似参数的行仍是正文。当前不支持正文含协议结束标记的转义，不能用于任意二进制/任意文档序列化。

真实执行结果作为有边界的观察返回，模型继续行动或生成最终剧本。中间草稿不进入 HDSI 正式历史。最终剧本不得保留动作标记。笔记场景另有基本的完成声明检查，发现未执行却描述保存/核对时退回；这是针对笔记的文本防线，不是对任意自然语言行动真实性的完备证明。

## 已提供的能力

- 查询时间：北京时间。
- 保存笔记：按标题创建或替换内容。
- 读取笔记：返回标题和完整正文；不存在则明确返回未找到。
- 列出笔记：最多 100 个标题。

笔记与行动回执在当前身份 `hdsi/actions.sqlite`，不会读写 WorldEdit、任意用户文件或 HDSI 自有记忆表。现已提供[天气与公开信息搜索](living-tools.md)，CLI/服务启用行动后自动注册；程序化使用 `createLivingTools` 注册。通用文件编辑尚未提供，原 LangGraph 工具注册表也没有自动接过来。

## 使用与扩展

CLI/服务 `.env` 设置 `FAMILA_CHAT_ENGINE=hdsi`、`FAMILA_HDSI_MODE=native`、`FAMILA_HDSI_ACTIONS=1`。程序化可使用：

```ts
import { startHdsiRuntime, type SceneTool } from 'famila-core-agent/hdsi'

const weather: SceneTool = {
  name: '查询天气',
  description: '查询指定城市的天气。',
  fields: ['城市'],
  async execute(fields, { signal, idempotencyKey }) {
    // 宿主在这里连接自己的服务，校验参数并尊重取消信号。
    // 有外部写入时，把 idempotencyKey 传给支持幂等的目标服务。
    return weatherService.query(fields['城市'], { signal })
  }
}
const runtime = await startHdsiRuntime(coreOptions, {
  mode: 'native', sceneActions: { tools: [weather], maxActions: 4 }
})
```

工具 execute 返回表示实际完成，而非仅受理。外部凭据保留在宿主闭包中，不放进描述或模型消息。当前 tools.fields 是字符串字段目录，复杂参数由宿主验证；不支持模型直接执行任意代码或 shell。

## 执行与恢复语义

内置笔记写入与成功回执在同一 SQLite 事务内提交。相同回合的同一动作序号及参数会复用回执；同一序号参数变化时不执行。外部工具先持久化 running，成功后保存回执；抛错、超时或重启遗留 running 会标记结果未知，禁止自动重复执行。不能承诺外部服务 exactly-once，外部服务需支持幂等或后续核实。操作完成后，最终叙事生成失败也不会回滚外部效果。

默认每个原生模型请求最多 4 个行动（可设 1–8），另外允许有限格式修正往返；整个代理调用最多 110 秒。适配器把主叙事超时设为 120 秒，保证外层有时间退出。回执按参与者、当前用户事件时间、事件 ID 和内容关联；单机单身份运行，未验收分布式或跨身份幂等。大量/敏感数据应由工具自行限制，观察不应被当成指令；宿主提供写入工具意味着向这个身份授予对应能力。

## 验证

`node --test tests/scene-actions.test.cjs`：解析边界、多行正文、事务笔记、重复执行、恢复参数冲突、外部结果未知不重试；原生 HDSI HTTP 闭环、未执行读取的完成声明退回、只提交最终叙事和情绪增量、重启后响应重放。

`node scripts/scene-actions-live.cjs`：真实模型保存、读取核对、正常重启后再读取；最多 8 请求，每请求 2048 输出 token、30 秒模型超时，独立报告目录。测试看数据库和执行回执，不仅看模型是否说“存好了”。此脚本付费，不能当作普通离线检查运行。

2026-11-15 最终真实测试通过：`evals/companion_zh/reports/scene-actions-live-1794735616639`。7 次模型请求，输入 50,106、输出 1,658 token；两条用户消息、两轮最终剧本、三条已完成工具回执（保存、核对读取、重启读取），无 fast 尾任务。最终笔记内容精确为“周六出门带雨伞”。首轮回复“存好了，也读了一遍，标题和内容都对，没丢字。”，重启后回复“在呢，刚又进去看了，还是‘周六出门带雨伞’，没变。”；分别约 27.30、25.54 秒。工具多轮处理仍会增加等待，本轮不做降延迟验收。

实施期间共进行 4 组有界真实测试，累计 20 请求、输入 144,246、输出 5,354 token，未换算货币费用。前三组发现并修正 provider 强制 JSON 阻止文本行动、保存回执被误当读取核对证据、多行正文开头多保留换行等问题，不计为通过样本。模拟测试覆盖了相应回归。最终全套集成测试 12/12、构建与边界检查通过；`git diff -- vendor/hdsi` 为空。
