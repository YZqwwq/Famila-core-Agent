# 聊天优先路径与验证边界

默认用户/隔离测试者路径为：组装上下文 → 直接表达 → 输出校验 → 原子保存 → 发送。普通聊天一次主模型调用；需要工具时沿用工具权限、执行记录与检查点，最多 6 次主模型调用。不存在先做任务分类、情绪分类、认知草稿再表达的固定前置链。

2026-11-10 起采用无人格语调基线：只注入 Famila 名称、AI 身份和事实边界。迁移人格、情绪表达状态、主体生活叙述和自我经历投影不进入正常聊天请求，也不通过即时 personaPolicy 改变生成参数。真实对话历史、工具与任务事实仍保留。旧人格存储没有物理删除，legacy 路径不在此次调整范围；后台情绪评价改用中性身份上下文，维护结果暂不用于聊天语调。原始 provider token 不直接呈现；完整正文保存成功后再发 text_delta/done。模型延迟和总上下文仍影响速度，未承诺真实提供商的 P95。

后台单 worker 根据持久化 observation cursor 每批处理最多 4 条：更新偏好/情绪、整理生活状态、归档记忆。模型请求在事务和记忆锁外；写回时核对人格/slot 快照及生活状态 revision，避免旧结果覆盖新状态。归档核对旧消息前缀，保留计算期间新加入的消息。进程正常关闭等待当前批次；未处理 observation 在下次启动恢复。失败计数可从内部 maintenance 状态读取，日志不包含模型原始响应。

注意：推断失败不等于对话失败。偏好推断沿用原先空信号回退；生活状态推断失败跳过本次更新；情绪失败保留 observation cursor 待后续请求/重启重试。当前后台与聊天仍共用部署资源，未做进程/提供商配额硬隔离。

兼容模式 `FAMILA_CHAT_MODE=legacy` 保留旧认知/表达与任务分类流程，用于基线回归。启动后不要动态修改此环境变量；不支持在未完成旧 checkpoint 中间切换模式。专业 Agent 委派适配器仍未接入。

本次完成的是短聊天路径与后台状态更新，并修正保存前发送正文的问题。尚未实现：连续短消息合并、未发送草稿重排、持久 outbox 与按 cursor 重放。当前仍一条用户消息对应一轮，SSE 断开后继续执行，历史接口恢复已提交消息；不能宣称完整消息投递协议已经完成。

验证：`npm test` 为现有 133 条回归；`npm run test:smoke` 含新聊天路径、后台阻塞隔离、工具回合、归档锁隔离、旧流程原生 SQLite 重启/去重/断线测试；`npm run test:companion` 为原创中文离线评测骨架。它们均不代表真实模型的聊天质量或真实网络延迟。
