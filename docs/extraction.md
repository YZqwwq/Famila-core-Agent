# Agent 内核迁移记录

## 来源与范围

来源为 `worldEdit-agent` 的 `master`，提交 `bd33f343bad50746f67ac65ac71bfe56fc9d6ab7`。原应用源码未删除或替换，也没有切换桌面端依赖。内核原目录结构保留用于对照。

目标是独立运行的 TypeScript Agent Harness：Node.js 运行内核，LangGraph 承载原执行图，Fastify 提供 Agent 自身服务入口。本轮不定义 WorldEdit 应用接口、不迁移原应用数据库、不实现通用编程子 Agent。

## 已迁移能力

- 感知、人格与情绪、上下文、认知/工具循环、表达、输出检查和记忆节点。
- 模型适配、工具发现与激活、工具预算、执行回执、回合版本和事务提交。
- 短期、阶段和长期记忆、中文历史召回、习惯、身份与生活状态。
- 主 Agent 事件队列、任务执行和通知协议、启动恢复。
- 22 个内核实体及独立数据目录；不引入世界编辑实体或原应用 schema 迁移。
- 从初次提取版本补回搜索、思考指南、活动任务查询、任务详情和继续子任务工具。

路径已脱离 Electron，提示词默认生活环境已改为独立 Famila Runtime。保留已有扩展挂点用于兼容，但当前启动不依赖任何 WorldEdit 业务实现。

## 独立运行适配

`src/runtime/familaRuntime.ts` 负责接收状态、请求跟踪、输出消费者隔离和退出排空；`src/server.ts` 提供消息 SSE、历史、状态和中断；`src/bin/` 提供终端与服务入口；`src/runtime/config.ts` 加载环境配置。

内核队列的重复请求原先提前 resolve，现改为等待同一事件完成，避免重复流连接提前结束。输出消费者抛错不再中断业务提交。关闭服务先停止接收与排空任务，HTTP 请求完成后再关闭数据库。

搜索仍为 DashScope 实现，增加独立搜索密钥及提供方检查，避免不同主模型提供方的密钥混用；增加 60 秒网络超时。

## 已知边界

- 一进程一身份、一次初始化生命周期，未实现多租户。
- 通用子 Agent 注册项仍未启用；人物编辑等业务执行器未搬入。
- SelfExperience 等高级自我演化模块存在，但原生产链路尚未完整写入。
- 重启可恢复 queued 事件和安全的 ready-to-commit 回合，不重放结果不明的工具动作。
- SSE 无历史事件回放；已完成的重复请求应通过历史读取结果。
- 真实模型和外部搜索需要实际配置后验收。

## 验证方式

内核回归在 sql.js 和原生 SQLite 上运行；服务测试使用 Fastify 注入；完整流程使用本机 HTTP 模型替身。独立进程验收覆盖并发请求去重、工具调用、连续对话归档、人格与生活状态重启保留、历史召回、queued 事件恢复、断开连接后的任务提交和 CLI 退出排空。

各次验证结果与文件哈希记录在 `extraction-manifest.json`。测试凭据和数据库均使用临时目录，不包含用户原应用数据。
